# Indian Club — Dirección de experiencia v1

## Tesis visual

La interfaz debe sentirse como una casa editorial y cultural, no como una plantilla de barbería ni como una landing generada por IA.

La dirección vigente es:

- Negro profundo como superficie dominante.
- Dorado cálido como señal de decisión, no como decoración constante.
- Tipografía display para memoria y manifiesto.
- Tipografía sans para navegación, datos y operación.
- Composiciones asimétricas y de gran escala.
- Uso deliberado del vacío.
- Fotografía cinematográfica con luz lateral.
- Motion que explica continuidad y jerarquía.

## Patrones que se evitan

- Secciones repetidas de tres tarjetas iguales.
- Gradientes neón intercambiables con una startup tecnológica.
- Glassmorphism indiscriminado.
- Iconografía ornamental sin función.
- Animaciones que retrasan contenido o bloquean el scroll.
- Textos genéricos como “vive una experiencia única”.
- Componentes importados sin adaptación al sistema visual.

## Política de librerías

Se pueden estudiar o reutilizar patrones de:

- Unlumen UI
- Magic UI
- Smooth UI
- Retro UI
- 21st.dev
- Origin UI / OriginKit
- DaisyUI
- Colecciones de partículas

La incorporación debe cumplir estas reglas:

1. Resolver un problema real de interacción.
2. Adaptarse a tokens, tipografía y motion de Indian Club.
3. Mantener accesibilidad y reduced motion.
4. No añadir una dependencia completa por un solo efecto.
5. No volver reconocible el sitio como una plantilla de terceros.
6. No degradar Core Web Vitals.

## Composición actual

- Hero editorial con retrato vertical y tipografía superpuesta.
- Navegación fija de baja densidad.
- Menú móvil inmersivo.
- Atlas de servicios basado en filas interactivas.
- Preview de servicio con composiciones gráficas propias.
- Manifiesto dorado de gran escala.
- Línea narrativa del ritual.
- Collage de club, café y cultura.
- Journal como índice editorial.
- Cierre de reserva con contraste negro/dorado.
