# Estructura pública de servicios

La web agrupa el catálogo de Indian Club en cuatro áreas visibles:

- Peluquería y barbería
- Combos y servicios especiales
- Tattoo Studio
- Nails Studio

Las rutas históricas de corte, barba y servicios especiales se conservan como alias para evitar enlaces rotos. Cada página de área muestra las opciones disponibles sin numeración decorativa y dirige la reserva a AgendaPro.
